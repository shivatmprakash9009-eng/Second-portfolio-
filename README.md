# Developer Portfolio

Responsive motion-led portfolio built with Next.js 15 App Router, React 19, TypeScript, Tailwind CSS v4, GSAP/ScrollTrigger and Framer Motion.

## Run locally

```bash
npm install
npm run dev
npm run lint
npm run build
```

Edit profile copy, project descriptions, images and contact details in `src/lib/data.ts`. The contact form validates and opens a prefilled `mailto:` draft; it does not send or store messages on a server. Replace the fictional profile details and example project links before publishing.
